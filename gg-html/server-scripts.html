Перед ручним запуском

Швидка перевірка сервера

Ці команди нічого не змінюють. Вони показують активні таймери, останні запуски, cron-конфігурацію та відомий success marker для daily Elo.

Один read-only блок

Виконайте після SSH-входу на сервер.

cd /home/carcassonne-gg/auth-server sudo systemctl list-timers --all \ update-duels.timer \ sync-wtcoc-matches.timer \ fix-matches-and-duels.timer \ update-player-elo-daily.timer \ update-player-elo-missing.timer \ cleanup-chrome-tmp.timer \ server-alerts.timer sqlite3 ./data/auth.sqlite \ "SELECT job_name,last_success_at,last_status FROM job_runs ORDER BY job_name;" crontab -l

Таблиця job_runs зараз фіксує success тільки для update-player-elo-daily; для решти jobs джерело істини — systemd та логи.

Де дивитися правду

Git показує задум, сервер — фактичний стан.

  • systemctl list-timersnext / last run
  • systemctl status …exit status
  • journalctl -u …system logs
  • /var/log/carcassonne/job logs
  • crontab -lJSON sync schedule
